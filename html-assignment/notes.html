HTML tags

main
The main tag is where the sites content goes, everything (other than the header and footer) is nested inside of here
img
The img tag allows you to put images in a website, you put the path to the image in the "src" attribute and you put a description of the image inside the "alt" attribute
dl
The dl tag is how you create a list like this one
button
the button tag is how you can add a to a web page, buttons are cool, they allow you to do things
a
the a (anchor) tag is how you can add a link to a web page, you just need to add the destination in the "href" attribute
